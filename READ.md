# Task API

A small task-management REST API built with [FastAPI](https://fastapi.tiangolo.com/),
[SQLModel](https://sqlmodel.tiangolo.com/), SQLite, and JWT authentication.

## Features

- User registration and password-protected login
- JWT bearer-token authentication
- User profile endpoint
- Create, list, view, update, complete, and delete tasks
- Task filtering by status and priority
- Pagination with `skip` and `limit`
- Role-based access control
  - Regular users can manage their own tasks
  - Administrators can view and manage all tasks
  - Only administrators can delete tasks
- Automatic SQLite database and table creation at application startup
- Interactive API documentation generated by FastAPI

## Requirements

- Python 3.10 or later
- `pip`

## Installation

1. Create and activate a virtual environment:

   ```bash
   python -m venv .venv
   ```

   On Windows:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

   On macOS/Linux:

   ```bash
   source .venv/bin/activate
   ```

2. Install the dependencies:

   ```bash
   pip install -r req.txt
   ```

## Configuration

Configuration is read from environment variables by `config.py`. The defaults
are suitable for local development:

| Variable | Default | Description |
| --- | --- | --- |
| `DATABASE_URL` | `sqlite:///./database.db` | SQLAlchemy database URL |
| `SECRET_KEY` | `my-secret-key` | Key used to sign JWT access tokens |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | `30` | Token lifetime in minutes |

For anything other than local development, set a strong, private `SECRET_KEY`
and provide configuration through environment variables rather than relying on
the defaults.

Example PowerShell configuration:

```powershell
$env:SECRET_KEY = "replace-with-a-long-random-secret"
$env:ACCESS_TOKEN_EXPIRE_MINUTES = "60"
```

## Running the API

Start the development server from the project directory:

```bash
uvicorn main:app --reload
```

The API is then available at <http://127.0.0.1:8000>.

Interactive documentation:

- Swagger UI: <http://127.0.0.1:8000/docs>
- ReDoc: <http://127.0.0.1:8000/redoc>

The SQLite database is created as `database.db` when the application starts if
it does not already exist.

## Creating an administrator

The registration endpoint creates regular users. To create an administrator,
run the helper script and follow its prompts:

```bash
python create_admin.py
```

The script stores the administrator in the configured database. Use the
administrator credentials with the login endpoint to obtain a bearer token.

## Authentication

Register or create a user, then log in using OAuth2 form data:

```bash
curl -X POST http://127.0.0.1:8000/auth/login ^
  -H "Content-Type: application/x-www-form-urlencoded" ^
  -d "username=alice&password=your-password"
```

On macOS/Linux, use `\` instead of `^` for line continuation.

The response contains an access token:

```json
{
  "access_token": "your-jwt-token",
  "token_type": "bearer"
}
```

Send the token on protected requests:

```text
Authorization: Bearer your-jwt-token
```

The Swagger UI at `/docs` also supports authentication through the
**Authorize** button.

## API endpoints

### Authentication and users

| Method | Path | Authentication | Description |
| --- | --- | --- | --- |
| `POST` | `/auth/register` | No | Register a regular user |
| `POST` | `/auth/login` | No | Log in and receive a JWT |
| `GET` | `/auth/me` | Bearer token | Get the current user |

### Tasks

| Method | Path | Authentication | Description |
| --- | --- | --- | --- |
| `POST` | `/tasks` | Bearer token | Create a task |
| `GET` | `/tasks` | Bearer token | List tasks visible to the current user |
| `GET` | `/tasks/{task_id}` | Bearer token | Get one task |
| `PATCH` | `/tasks/{task_id}` | Bearer token | Update task fields |
| `PATCH` | `/tasks/{task_id}/complete` | Bearer token | Mark a task as complete |
| `DELETE` | `/tasks/{task_id}` | Admin only | Delete a task |

`GET /tasks` accepts these optional query parameters:

- `status`: `todo`, `in_progress`, or `done`
- `priority`: `low`, `medium`, or `high`
- `skip`: Number of records to skip; defaults to `0`
- `limit`: Maximum number of records to return; defaults to `10`

Example task request:

```bash
curl -X POST http://127.0.0.1:8000/tasks ^
  -H "Authorization: Bearer your-jwt-token" ^
  -H "Content-Type: application/json" ^
  -d "{\"title\":\"Prepare release\",\"description\":\"Review the API documentation\",\"priority\":\"high\"}"
```

Example filtered list request:

```text
GET /tasks?status=todo&priority=high&limit=20
```

## Project structure

| File | Purpose |
| --- | --- |
| `main.py` | Creates the FastAPI application and initializes the database |
| `route.py` | Authentication and task API routes |
| `model.py` | SQLModel database models and request/response schemas |
| `database.py` | Database engine, table creation, and session dependency |
| `security.py` | Password hashing and JWT creation/decoding |
| `dependencies.py` | Current-user and role-based authorization dependencies |
| `enums.py` | Task status, priority, and user role values |
| `config.py` | Environment-backed application settings |
| `create_admin.py` | Interactive administrator creation script |
| `req.txt` | Python dependency pins |

## Notes

- Passwords are stored as hashes, not plaintext.
- Access tokens expire according to `ACCESS_TOKEN_EXPIRE_MINUTES`.
- Do not commit production secrets or a production database file to source
  control.
